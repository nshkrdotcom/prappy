# Prappy

Prappy is a collection of native Windows apps for sound, graphics, and the desktop.

- **[Prappy](apps/prappy/README.md)** — A visualization workbench for maps, particles, and other real-time graphics.
- **[Prappy Player](apps/prappy-player/README.md)** — A compact music player for local files, with a collapsible library and always-on-top mode.

Each app has its own build and dependencies. Follow its README for setup and controls.
Both use C++20 and build with MSVC, CMake, and Ninja.

App code is [MIT licensed](LICENSE). Third-party dependencies keep their own licenses.
